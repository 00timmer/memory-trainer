# Memory Trainer 编码速度训练

单文件 HTML 记忆编码训练器（数字人物编码 / 扑克牌 / 地点编码 / 自定义牌组）。
所有数据存在浏览器 localStorage，无后端、无账号。

**在线使用：** https://00timmer.github.io/memory-trainer/

## 训练模式
随机闪卡、反向闪卡、易混淆对、冲刺挑战、弱项复习、多编码连读、顺序记忆

## 本地运行
直接用浏览器打开 `index.html` 即可。
